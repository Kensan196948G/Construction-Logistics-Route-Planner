| 項目 | 内容 |

| 目的 | 土木・建設工事の資材搬入・重機回送ルートの**初期検討**を標準化し、注意箇所・追加確認先・協議資料を生成する |

## 4. 強み（15 件以上）

1. 安全側判定方針と常時サンプル明示（UI・帳票・API に本番利用禁止表示）

5. Entra ID OIDC＋API キー＋4 ロール RBAC
6. 監査ログの永続化と admin CSV エクスポート
7. 確認（confirmed/needs_review/not_applicable）→ 提出 → 承認/差戻しワークフロー
8. OSRM 実ルーティング・Overpass 実地物取得の切替オプション
9. リスクルール ID 管理（RR-BRIDGE-001 等）による説明可能性

14. 依存最小・MIT ライセンス・非 root Docker＋HEALTHCHECK

| セキュリティ・監査 | 10% | 60% | 80% | RBAC・監査・フェイルクローズ・ヘッダー・レート制限。Entra 実接続・TLS 前段は未設定 |

- 80% 到達必須項目: 実道路ネットワーク＋規制属性（商用/自前ルーティング）、Entra ID 実接続、Neon PostgreSQL 本番＋バックアップ検証、Excel 帳票、プロジェクト編集・削除（論理）、ユーザー/ロール管理 UI、監査ログ検索 UI、案件検索・ページング、監視アラート実配信
